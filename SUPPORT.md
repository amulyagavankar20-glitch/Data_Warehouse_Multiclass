# Support

| Need | Where to go |
| :-- | :-- |
| How do I run, deploy or retrain it? | [Operations runbook](docs/operations.md) and [development guide](docs/development.md) |
| What does an endpoint expect or return? | [API specification](docs/api-spec.md), or `/docs` on a running service |
| Why did validation reject my data? | [Data contract](docs/data-contract.md) |
| How good is the model, and where does it fail? | [Model card](docs/model-card.md) |
| I found a bug | [Open a bug report](../../issues/new?template=bug_report.yml) |
| I have an idea | [Open a feature request](../../issues/new?template=feature_request.yml) |
| I found a security problem | Follow the [security policy](SECURITY.md); **do not** open an issue |

> [!NOTE]
> The project is maintained on a best-effort basis by
> [@KrishKamra](https://github.com/KrishKamra) and
> [@amulyagavankar20-glitch](https://github.com/amulyagavankar20-glitch).
> Clinical questions about individual patients are out of scope.
